# 🔍 Glasspect — Glassmorphic CSS Inspector Extension

**Glasspect** is a lightweight, modern Chrome Extension built with Manifest V3 that allows developers and designers to inspect CSS properties in real-time using a sleek, glassmorphic UI overlay.

---

## ✨ Features

* **Real-time CSS Inspection:** View dimensions, text color, background color, font styles, padding, and margin on mouse hover.
* **Smart Asset Detection:** Automatically distinguishes image assets (`<img>`) from solid CSS background colors.
* **Element Hierarchy:** Displays HTML tags along with primary IDs or CSS classes (e.g., `<button.primary-btn>`).
* **Freeze Control (Spacebar):** Press `Space` to lock the inspector card in place without triggering page links or navigation.
* **Click-to-Copy:** Click any CSS value inside the frozen card to copy it directly to your clipboard.
* **Glassmorphic UI:** Styled with CSS backdrop blur and modern gradients for an aesthetically pleasing developer experience.

---

## 🛠️ Built With

* **JavaScript (ES6+)** — Extension logic, DOM manipulation, and Messaging API.
* **CSS3** — Backdrop filters, glassmorphism design, and modern layouts.
* **HTML5** — Popup interface structure.
* **Chrome Extension API** — Manifest V3.
